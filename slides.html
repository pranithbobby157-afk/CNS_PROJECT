Critical Retrospective: Auditing Gao et al. (2025)

1. Inverted Propensity Score & Sparsity

Defined as $e(T_i) = P(X_i \mid T_i)$ instead of $P(T \mid X)$. Discretizing $CMB$ into $|NC|^n$ joint cells created $>10^{11}$ empty bins (catastrophic sample sparsity with $>99.9999\%$ empty strata).

2. Algorithmic Self-Conditioning Bug

Algorithm 1 tested $X \perp Y \mid CMBS$ while $X \in CMBS$. Conditioning on $X$ makes the test mathematically trivial ($I \equiv 0$), while in-place list mutation skipped adjacent features.

3. The "Accuracy Paradox" on Stealth Attacks

Headline accuracy exceeded 98.8%, but published tables revealed: Infiltration was 2.78% (1/36 detected) and SQL Injection was 23.81% (5/21 detected) in CIC-IDS2017. In CSE-CIC-IDS2018, ablated model fell to 16.67%.

4. Invalid KL & Cascading Errors

Evaluated KL-divergence on raw signed vectors (invalid math). The CVAE conditioned strictly on upstream top-1 predictions, allowing zero-days to evade detection under wrong labels.

Conclusion: High headline accuracy was an illusion created by overwhelming volumes of benign and volumetric DoS traffic.

IR-IDS 2.0: Modular Architectural Blueprint

1. Causal Selection (DS-CMI)

Dirichlet-smoothed Conditional Mutual Information with equal-depth quantile bins. Tests $X \perp Y \mid (CMB \setminus \{X\})$, eliminating division-by-zero.

2. Cost-Sensitive Ensemble

HistGBDT trained under Balanced Focal Loss: $w_c = (N / (K \cdot N_c))^\gamma$. Prevents rare stealth intrusions from being suppressed by high-volume flood attacks.

3. Marginalized Free Energy

Evaluates Ledoit-Wolf Mahalanobis distance across all class hypotheses: $E(x) = -\log \sum_k p(y=k \mid x) e^{-\frac{1}{2} \mathcal{D}(x, \hat{x}^{(k)})}$.

4. Dynamic POT-EVT Detector

Replaces static 0.9 quantile with Generalized Pareto Distribution (GPD) solved via Grimshaw's Probability Weighted Moments, bounding False Alarm Rates.

5. Authentic Symbolic KAN Extraction

Chebyshev polynomial basis expansions pruned via $L_1$ regularization to export explicit closed-form algebraic equations for security audits.

Theoretical Foundations & Formal Proofs

Theorem 1: Breakdown of Graph Faithfulness

Claim: Deterministic network protocols ($X_{\text{total}} = X_{\text{fwd}} + X_{\text{bwd}}$) inherently violate Bayesian DAG faithfulness via path cancellation ($\sum_k \beta_k = 0$).

Solution: IR-IDS 2.0 reformulates causal feature discovery under Multi-Environment Invariant Risk Minimization (IRM), guaranteeing that only structural causal features survive.

Theorem 2: Error-Bounded Zero-Day Isolation

Claim: Let an unobserved zero-day attack $x^*$ lie at minimum Mahalanobis distance $\delta > 0$ from all known class manifolds. The Marginalized Free Energy satisfies:

E(x*) ≥ ½ δ²

Significance: Zero-day attacks cannot bypass detection through upstream classification errors, mathematically eliminating cascading failure.
